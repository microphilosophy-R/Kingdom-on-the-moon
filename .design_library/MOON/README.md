# MOON Design System

A design system reconstruction of **MOON** — a Chinese-language, space-fiction operations interface covering fleet, star-chart, and mission-control screens.

> No original brand tagline was supplied.

## Source

- **Brand bundle:** `phase2-brand-analyst.json` is empty; the system was rebuilt from generated CSS and preview artifacts.
- **Generated artifacts:** `colors_and_type.css`, `components.css`, and six preview pages.
- **Brand owner:** inferred from preview copy (space operations / fleet command).

## What this design system covers

- **Foundations** — color (nebula violet + signal orange), type (Orbitron / Noto Sans SC / JetBrains Mono), spacing, radius, shadow.
- **Components** — 6 documented components: Button, Card, Input, Navigation, Modal, Tag.
- **Previews** — static HTML cards under `preview/`.

## CONTENT FUNDAMENTALS

### Voice & tone

The UI speaks Chinese first, in short, functional labels that read like a heads-up display. Copy is diegetic: it names ships, star systems, and mission objects rather than using generic UI placeholders. Sentences are brief, punctuation is minimal, and the tone is technical but not cold — it wants the operator to feel like a commander reading a console.

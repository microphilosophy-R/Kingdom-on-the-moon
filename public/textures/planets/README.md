# Planet Texture Attribution

The five texture files in this directory are downloaded from Wikimedia Commons file redirects for Solar System Scope texture maps:

- `mercury.jpg`: Solarsystemscope texture 2k mercury
- `venus.jpg`: Solarsystemscope texture 2k venus surface
- `earth.jpg`: Solarsystemscope texture 2k earth daymap
- `mars.jpg`: Solarsystemscope texture 2k mars
- `moon.jpg`: Solarsystemscope texture 2k moon

Solar System Scope distributes these texture maps under Creative Commons Attribution 4.0 International. The maps are equirectangular and are intended for 3D planet surfaces.

# 王月报告概览区块（PalaceReportBlock）重新设计 — 实现计划

## Summary

重新设计 K 王城页的王月报告概览区块（`PalaceReportBlock`）：移除与完整报告弹窗重复的 KPI 三栏，改为「图主导」布局——资源切换器 + 可切换库存趋势主图 + 摘要行 + 人口 mini 副图 + 精简建议区；无报告时增强空状态（倒计时 + 周期进度条），消除重复与空白内容。`ReignReportModal`（完整报告弹窗）、`TrendChart` 组件、数据结构与存档均不动。

## Current State Analysis

- `PalaceReportBlock` 位于 `src/components/business/SpecialBlocks.tsx` 40-86 行：
  - 工具栏：标题 + `reportProgress` 百分比 + 日期范围
  - `policy-status` KPI 三栏（人口变化/GDP/阶段）——**与 `ReignReportModal.tsx` 66-68 行 KPI 完全重复**
  - 「打开完整报告」按钮
  - `palace-report-preview` 两栏：资源趋势 mini 图（合金/货币/人口固定三线，**不可切换**）+ 建议列表
- 数据：`ReignReport.trendPoints: TrendPoint[]`（每王月 50 个点，每天 1 点，`day` 初始 1、首份报告在御日 50 归档）。`TrendPoint` 字段：`day/population/alloy/currency/water/oxygen/biomass/regolith/knowledge/power/luxury/gdp/netAlloy/netKnowledge/netCurrency`（**无 quantumCore**）。`resourceRows` 每资源 produced/consumed/net；`suggestions: string[]`。
- `TrendChart`（`src/components/business/TrendChart.tsx`）：非 mini 模式自带边框卡片、标题、图例、空数据 fallback 表格；mini 空数据返回 null。无资源切换能力（由外层实现）。
- `resourceUiMeta`（`src/components/resources/resourceMeta.ts`）：每资源 `{ label, icon, tone }`，已由 `resources/index.ts` re-export。
- `policy-status` CSS 类全仓库仅 `SpecialBlocks.tsx` 61 行一处使用（CSS 在 `SpecialBlocks.module.css` 33-67、959-962 行）。
- `fmt` import（SpecialBlocks.tsx 21 行）仅 KPI 使用，移除 KPI 后需裁剪。
- 设计体系：oklch 色彩、`--ui-serif/--ui-mono/--ui-brass-dark/--ui-line/--ui-raised/--ui-ink/--ui-muted` token、`--font-card/--font-body/--font-note/--font-micro`。
- 现有资源线色惯例：合金 `oklch(58% .16 28)`、货币 `oklch(62% .12 85)`、知识 `oklch(58% .14 296)`、人口 `oklch(55% .14 142)`。

```tsx
const REPORT_TREND_RESOURCES = [
  'power', 'water', 'oxygen', 'biomass', 'regolith',

const RESOURCE_TREND_COLORS: Record<ReportTrendResource, string> = {
  power: 'oklch(55% .13 76)',
  water: 'oklch(58% .12 205)',
  oxygen: 'oklch(52% .10 225)',
  biomass: 'oklch(55% .12 150)',
```

**import 调整：**

- 第 1 行 `react` 追加 `type CSSProperties`
- 第 21 行移除 `fmt`（仅 KPI 使用），保留 `displayCopy`/`fmtAmount`/`formatDay`

**组件内部改动（40-86 行）：**

- `miniSeries` 替换为单线 `populationMiniSeries`（仅人口，沿用 `oklch(55% .14 142)`）

- 摘要值：从 `trendPoints[0]` / `trendPoints[last]` 取 `startVal` / `currentVal` / `delta`
- fallback 行：`resourceOrder.filter(key => resourceRows[key])` 生成（与弹窗同模式），供空 trendPoints 时主图表格回退

**有报告分支 JSX：**

```tsx
<>
  <div className={styles['palace-report-actions']}>
    <button className="primary-action" onClick={() => onOpenReport(lastReignReport)}>
      <BookOpen size={15} />打开完整报告
    </button>
  </div>
  <div className={styles['palace-report-preview']}>
    <div className={styles['report-main-col']}>
      <div className={styles['report-chips']} role="group" aria-label="选择趋势资源">
        {REPORT_TREND_RESOURCES.map(key => {
          const meta = resourceUiMeta[key]
          const Icon = meta.icon
          const active = key === selectedTrend
          return (
            <button key={key} type="button"
              className={`${styles['report-chip']} ${active ? styles.active : ''}`}
              style={{ '--chip-color': RESOURCE_TREND_COLORS[key] } as CSSProperties}
              aria-pressed={active}
              onClick={() => setSelectedTrend(key)}>
              <Icon size={12} />{meta.label}
            </button>
          )
        })}
      </div>
      <div className={styles['report-summary']}>
        <div><span>起始值</span><b>{startVal !== null ? fmtAmount(startVal) : '—'}</b></div>
        <div><span>当前值</span><b>{currentVal !== null ? fmtAmount(currentVal) : '—'}</b></div>
        <div><span>本王月变化</span>
          <b className={delta !== null && delta < 0 ? styles.negative : ''}>
            {delta !== null ? `${delta >= 0 ? '+' : ''}${fmtAmount(delta)}` : '—'}
          </b>
        </div>
      </div>
      <TrendChart
        data={lastReignReport.trendPoints}
        series={[{ key: selectedTrend, label: resourceUiMeta[selectedTrend].label, color: RESOURCE_TREND_COLORS[selectedTrend], accessor: p => p[selectedTrend] }]}
        title={`${resourceUiMeta[selectedTrend].label}库存趋势`}
        fallbackRows={fallbackRows}
      />
    </div>
    <aside className={styles['report-side-col']}>
      {lastReignReport.trendPoints.length > 0 && (
        <section className={styles['report-side-card']}>
          <h3>人口趋势</h3>
          <TrendChart data={lastReignReport.trendPoints} series={populationMiniSeries} mini />
        </section>
      )}
      <section className={styles['report-side-card']}>
        <h3>本期建议</h3>
        {lastReignReport.suggestions.length > 0 ? (
          <ol>{lastReignReport.suggestions.slice(0, 2).map(item => <li key={item}>{item}</li>)}</ol>
        ) : (
          <p className={styles['report-suggestions-empty']}>本期无新增建议，各系统运转平稳。</p>
        )}
      </section>
    </aside>
  </div>
</>
```

要点：主图不套外层 `<section>`（TrendChart 非 mini 自带卡片，避免双重边框）；人口 mini 在空点时整体隐藏；建议空时渲染文案而非空 `<ol>`。

**空状态分支（无报告时）：**

```tsx
<div className={styles['palace-report-empty']}>
  <BookOpen size={22} />
  <span>尚未形成可复核的王月报告</span>
  <div className={styles['report-countdown-bar']}><i style={{ width: `${reportProgress}%` }} /></div>
  <small>
    距首份报告归档还有 {gameCalendar.reignMonthDays - (day % gameCalendar.reignMonthDays)} 御日
    · 已推进 御日 {day % gameCalendar.reignMonthDays} / {gameCalendar.reignMonthDays}
  </small>
</div>
```

数学依据：day 初始 1、首份报告在御日 50 归档，剩余 = 50 − (day % 50)。

## Assumptions & Decisions

- 默认选中 `alloy`（合金）：人口已有 mini 副图，默认人口会造成主副图重复
- 切换器资源 10 种（排除 quantumCore，TrendPoint 无此字段）
- 主图单 series（单资源），颜色由显式色表给出；`color-mix` 生成 chip 激活浅底，无需逐资源写类
- 建议区 `slice(0, 2)` 精简（弹窗显示全部），空时显示平衡文案
- 不新增 KPI 替代展示（GDP/阶段由弹窗承担，避免二次重复）

# 计划：新手教程完成度评估与改进

## 摘要

评估并改进「月冠纪元」的新手教程系统，让玩家在开局即明白核心玩法循环：**建造并扩建建筑以生产足够资源来建造星舰，期间通过指定科研计划、调整资源分配、应对外星人事件来取得更多优势**。

本次改进包含三部分：
1. **评估当前教程完成度**（约 40%）：5 步 UI 导览仅指认界面区域，对核心玩法教学停留在"一句话描述"层面。
2. **扩展教程步骤**：从 5 步扩展到 10 步，覆盖建造建筑、生产资源、资源分配、科研计划、星舰建造、星海贸易、外星人事件七项核心玩法（保持纯 UI 导览式，不引入交互式任务驱动）。
3. **补齐里程碑日志**：实现设计文档中规划但未落地的 10 条全程阶段提醒（100/200/.../950 御日）。

## 假设与决策

1. **保持纯 UI 导览式架构**：不引入交互式任务驱动教学（如"建造一个水厂才能进入下一步"）。教程仅通过高亮 + 文字引导，玩家可随时跳过。这是用户明确选择的方案，实现简单且不破坏现有架构。
2. **不切换视图**：教程组件不控制 `view` 状态，新增的科技/星舰/贸易/异客步骤通过指向 `.tab-nav button[data-tab="..."]` 标签按钮 + 文字描述引导玩家自行切换视图。
3. **不新增重看入口**：本次不在 SettingsPanel 中添加"重看教程"按钮（用户未要求）。如需重看，仍需手动清除 localStorage 的 `lunar-crown-tutorial-seen`。
4. **里程碑日志文案采用设计文档原文**：保持与已审阅设计文档的一致性，不重新撰写。
5. **步骤顺序固定线性**：不根据玩家操作动态调整，保持 1→10 的固定流程。
6. **资源分配步骤的可接受局限**：步骤 4 在初始视图下可能看不到 FacilityDetailPanel 的 staffing 控件，仅靠文字引导。这是纯 UI 导览式的固有局限，可接受（交互式教学才能解决，但本次不采用）。

# 2. 建筑系统

## 2.1 总则

本章是建筑系统的唯一规则来源。后续实现、UI、数值平衡与文案，均以本章为准。

- 建筑代号仅用于索引，不改变建筑名称本身。
- 建筑分为普通建筑与特殊建筑。普通建筑使用通用详情页，展示配方、规模、当前产量和扩建成本；特殊建筑使用专属界面，展示其专属机制。
- 特殊建筑固定为 D 冠冕星舰坞、R 月穹生态环、S 星海交易港、K 月面王城、L 问天研究实验室。
- 其余建筑为普通建筑：E1 日冕能源署、E2 月冕能源署、E3 归元装置、C1 静海采掘署、C2 西海采掘署、B 水培生态球、F 天工精炼署、P 伊犁河谷、H 翡翠宫、M 新月府。
- 建筑规模提升与缩小，均以 1 个人口单位为基本步长。
- 普通建筑始终处于“扩大 / 保持 / 缩小”三态之一，扩产与减产由算法执行，玩家只设置权重。
- 所有设施都在初始地图上，点击后进入详情页。
- 所有建筑都由建造科技解锁，包括初始建筑；建造科技统一使用 `T建筑代号-0` 编号。
- 初始默认具备所有早期建筑科技：`TE1-0`、`TC1-0`、`TK-0`。
- 科技未解锁前不可建造对应建筑；即使生产方式表中已有对应配方，也不得提前建造或运行。
- 建筑配方必须引用本章的生产方式表，不允许在实现中使用隐式产出、隐式消耗或旧别名。
- 建筑科技、通用科技与政策规则统一见 [科技与政策](technology-policy.md)。

## 2.2 建筑配方编码规则

建筑生产方式使用 `MX-n` 编码：`M` 表示生产方式，`X` 表示建筑代号，`n` 表示同一建筑下的生产方式序号。例如 `ME1-1` 表示 E1 日冕能源署的第 1 种生产方式。

生产方式表中的输入 / 输出均按每 1 个人口单位或等效建筑单位计算。未列出的资源视为 0。科技只负责解锁对应生产方式，不会自动改变当前生产方式；当前生产方式必须由玩家或算法在已解锁生产方式中选择。

若生产方式的解锁条件为“阶段推进”，该生产方式只由对应特殊设施的阶段状态启用，不参与普通生产方式选择；未实现阶段状态前，不能把后续阶段默认为当前产出。

## 2.6 E1 日冕能源署

建筑类型：普通建筑，能源建筑。

解锁条件：`TE1-0 日冕能源署建造许可`；初始默认具备。

界面职责：展示配方、当前产量、规模和扩建成本。

关联资源：电力、氧气、水。

关联生产方式：`ME1-1` 光伏发电；`ME1-2` 纳米光催化发电。

运行规则：

- 默认使用 `ME1-1`：无输入，输出电力。
- 解锁 `TE1-1 纳米光催化剂` 后，`ME1-2` 成为可选生产方式；只有切换到该方式时才增加水资源输入，并额外输出氧气。
- E1 是基础电力来源之一；电力不进入库存模拟，也不可交易。

## 2.7 E2 月冕能源署

建筑类型：普通建筑，能源建筑。

解锁条件：`TE2-0 月冕能源署建造许可`。

界面职责：展示配方、当前产量、规模和扩建成本。

关联资源：电力、月壤。

关联生产方式：`ME2-1` He3 聚变发电。

运行规则：

- `ME2-1` 消耗月壤，输出电力。
- 月壤出现赤字并超过规则阈值时，依赖月壤的生产建筑停止运行，直到恢复为盈余。

## 2.8 E3 归元装置

界面职责：展示配方、当前产量、规模和扩建成本；科技未解锁时显示锁定状态。

关联资源：电力。

关联生产方式：`ME3-1` 微型黑洞压缩。

运行规则：

- `ME3-1` 由 `TE3-0` 解锁。
- 归元装置通过微型黑洞压缩物质获取能量，不消耗资源。
- 科技未解锁时，E3 不可建造，不可运行，也不可被自动化扩建算法选中。

## 2.16 R 月穹生态环

建筑类型：特殊建筑，生态改造项目。

解锁条件：`TR-0 月穹生态环建造许可`。

专属界面：展示四阶段工程进度、阶段投入、阶段回报和暂停状态。

关联资源：电力、水、氧气、生物质、月壤、合金。

关联生产方式：`MR-1` 气候改造装置建设；`MR-2` 大气改造；`MR-3` 生态改造；`MR-4` 回报阶段。

阶段 / 专属规则：

1. 气候改造装置建设阶段：投入合金和能源，没有产出。
2. 大气改造阶段：需要投入大量氧气。
3. 生态改造阶段：需要投入大量水，以及一定的月壤和生物质。
4. 回报阶段：没有资源消耗，随着进度提高逐渐产出；解锁科技可以加速推进。

月穹生态环完成后，达到最大产值。它是一个投资型项目，前期吸收多余资源，可随时暂停；中期集中投入资源与人力；后期释放人力与资源到胜利目标建筑。

## 2.17 S 星海交易港

建筑类型：特殊建筑，贸易建筑。

解锁条件：`TS-0 星海交易港建造许可`。

专属界面：展示双向贸易、手动补充与自动购买状态。

关联资源：水、氧气、生物质、月壤、合金、量子计算核心、星海货币、人口、知识、艺术奢侈品。

关联生产方式：`MS-1` 贸易结算。

阶段 / 专属规则：

- 星海交易港不产生固定年净值，双向贸易、手动补充和自动购买由交易界面处理。
- 星海交易港不需要消耗人力运行。
- 星海货币是交易港的结算货币；当星海货币出现赤字时，自动购买暂停，恢复为盈余后继续交易。
- 当前所有星港科技均为双向贸易科技，不存在只进不出的单向星港科技。
- 解锁 `TS-1 星际劳工` 后，可处理其它星域人力资源的双向贸易。
- 解锁 `TS-2 知识传输协议` 后，可处理知识的双向贸易。
- 解锁 `TS-3 玫瑰星球` 后，可处理艺术奢侈品的双向贸易。

阶段 / 专属规则：

- 冠冕星舰坞是 Demo 版本游戏的胜利目标建筑，后续可扩展出其他类似的胜利目标建筑。
- 星舰坞中默认运行一个远洋星舰项目。
- `MD-1` 消耗电力、合金、量子计算核心、星海货币和人口，不产生普通库存资源。
- 扩大建筑规模、解锁科技、保证物资与人力供应，都可以加速项目推进。

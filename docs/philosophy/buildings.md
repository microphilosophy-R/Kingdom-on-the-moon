# 2. 建筑系统

> 本文档说明 `src/economy/facilities.ts` 与 `src/economy/calendar.ts` 的建筑实现。文档可能滞后，若与代码不一致，以代码为准。

## 2.1 总则

- 建筑代号仅用于索引，不改变建筑名称。
- 建筑分为普通建筑与特殊建筑。特殊建筑使用专属界面：K 月面王城、L 问天研究实验室、R 月穹生态环、S 星海交易港、D 冠冕星舰坞；其余为普通建筑（含 E3 归元装置）。
- 每座建筑都由 `T建筑代号-0` 建造许可解锁；初始默认具备 `TE1-0`、`TC1-0`、`TK-0`、`TB-0`、`TS-0`（`defaultStartingTechs`）。
- 非住房、非固定设施每级 4 岗位；住房容量 K=8 / H=16 / M=24；S 为固定设施，不可扩建（`maxLevel: 1`）。

## 2.3 生产方式编码

生产方式使用 `MX-n` 编码：`M` 表示生产方式，`X` 表示建筑代号，`n` 表示序号。输入 / 输出均为「每岗位每御日」数值（`src/economy/facilities.ts`）。科技只解锁生产方式，不自动切换；当前生产方式由玩家或算法在已解锁方式中选择。

## 2.7 特殊建筑专属界面

- K 王城：人口、税收、王月报告（`PalaceReportBlock`）。
- L 问天研究实验室：科技树（`ResearchTreeBlock`）。
- R 月穹生态环：四阶段进度（`EcologyPhaseBlock`）。
- S 星海交易港：双向贸易、自动购买保护（`TradeBoardBlock`）。
- D 冠冕星舰坞：御座号进度、三阶段物资（`ShipProgressBlock`）。

## 2.8 扩建成本

扩建成本由 `projectFacilityCost` 计算：`baseUpgradeCost × getUpgradeCostScale(建筑) × 下一等级 × 分段系数(≤5 级 0.8 / 6-10 级 1.0 / ≥11 级 1.5) × 难度系数 × TG-3 折扣`。各建筑的 `baseUpgradeCost` 见 `facilities.ts`。

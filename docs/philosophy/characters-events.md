# 4. 角色与事件链

## 4.1 总则

本章是外星角色与事件链的规则来源。角色与事件是两个独立数据容器：角色保存身份、专长、雇佣加成与美术占位字段；事件链保存相遇文本、阶段、交互类型、资源变化与科技奖励。

设计原则：

- 不做简单随机重复事件，避免玩家被同质事件打断。
- 每个角色均拥有完整长事件链（2–3 个节点），不再使用单事件简单链作为角色剧情；玩家在早期或中期投入，回报集中在后期。
- 事件链按时期分级（early / mid / late），与设施建设进度联动解锁，避免前期一次性涌现全部角色剧情。
- 外星科技必须引用 [科技与政策](technology-policy.md) 的外星科技索引，不得临时发明科技。
- 本阶段不生成美术资源；角色数据只保留 `glyph`、物种、肖像文本等可替换占位字段。

## 4.2 数据容器

角色容器字段：

```text
角色代号
角色名称
物种 / 来源
视觉占位 glyph
肖像文本
专长设施
雇佣加成
留任成本
代表台词
```

事件链容器字段：

```text
事件链代号
关联角色代号
链类型：simple / long
时期：early / mid / late
事件节点列表
```

事件节点字段：

```text
事件代号
事件标题
事件正文
互动类型
资源收入
资源支出
科技奖励
是否隐藏结果
是否推进下一节点
```

## 4.3 互动类型

| 类型 | 用途 |
| --- | --- |
| 物资换科技 | 以存储物资获取特定科技。 |
| 星港贸易授权 | 固定在 S 星海交易港添加贸易方式后获得科技，尤其用于贸易类科技。 |
| 雇佣角色 | 花费资源或直接留任，为特定区域或全局带来加成。 |
| 收下礼物 | 无资源支出，获得物资或科技。 |
| 索取资源 | 对方请求资源，可能推进后续事件链。 |
| 意外结果 | 无明确数值提示，需要玩家从文字推断，可能损失或获得资源。 |
| 稀有资源交易 | 交易获得量子计算核心、艺术奢侈品等稀有资源。 |
| 长链抉择 | 多节点人物事件中的阶段性选择。 |

## 4.5 长事件链（早期）

### 4.5.1 萨瓦·碎光（sava-catalyst）

1. 逆燃晶体（物资换科技）：支付水 10，获得量子计算核心 1、知识 12，并授予 `TE1-1 纳米光催化剂`。萨瓦用月面水样校准一枚向内塌缩、吞光不发的晶体。
2. 深层校准（索取资源）：支付水 8、月壤 8，获得知识 8、氧气 15。晶体适应月面水后索要更多水样，把光伏阵列校准推进到第二层。
3. 共振泄漏（意外结果，隐藏结果）：获得知识 15、氧气 20（支出水 5、月壤 6）；或仅获得知识 3（支出水 12、月壤 10）。

该链刻画能源科技与月面水资源的取舍：第一节点直接提供纳米光催化剂，后两节点是随机收益与风险。

### 4.5.2 梅露·第九孢（melu-waterless）

1. 干燥孢囊（收下礼物）：获得氧气 15、生物质 12，并授予 `TB-2 无水栽培技术`。孢囊里封着的是一整段不需要雨的生态记忆。
2. 孢壁扩张（索取资源）：支付月壤 20、水 8，获得生物质 18、氧气 15。根须想要更多空间和养分，铺满整座生态球。

该链是生态农业的正向投入：前段白送技术与资源，后段以月壤、水换取更大产出。

## 4.6 长事件链（中期）

### 4.6.1 尼克斯·二十七（nix-labor）

1. 退役礼仪机的名册（星港贸易授权）：支付合金 60、星海货币 40，获得星海货币 15，并授予 `TS-1 星际劳工`；固定在星海交易港添加人口 / 劳工双向贸易权限。
2. 审计子程序（意外结果，隐藏结果）：获得星海货币 30、知识 20（支出星海货币 8）；或损失星海货币 20、合金 15。七层旧主徽记中自行激活的审计逻辑存在两种结局。
3. 旧约移民条款（长链抉择）：支付星海货币 30、生物质 20，获得人口 2。将两名星际劳工正式转入月面居民名册。

该链从劳工贸易过渡到移民条款，是中期人口增长的一条隐蔽路径。

### 4.6.2 塔罗·掘井者（taro-alchemy）

1. 小行星矿脉图（物资换科技）：支付氧气 30、合金 10、知识 15，获得月壤 80、合金 20，并授予 `TF-1 重原子炼金术`。
2. 深层矿脉（意外结果，隐藏结果）：获得月壤 100、合金 15（支出星海货币 10、氧气 12）；或仅获得月壤 30（支出星海货币 8、合金 10）。钻错方向，钻头只会烧在石英里。
3. 亡星记忆（稀有资源交易）：支付月壤 60、氧气 20，获得合金 30、知识 20。翻译一颗死去小行星的记忆，不需要精炼炉就能直接析出合金晶格。

该链围绕采掘与炼金展开，重原子炼金术是采掘工业的核心科技。

### 4.6.3 伊芙·回声（evi-echo）

1. 回声接入（意外结果，隐藏结果）：两条支路均授予 `TS-2 知识传输协议`——获得知识 20（支出星海货币 41），或获得知识 10（支出星海货币 16、合金 15、知识 10）。
2. 建造谐振器（索取资源）：支付合金 15、星海货币 10，获得知识 30。没有物理载体的共鸣撑不了太久，稳定的声学群体会产出稳定的知识流。
3. 遗忘的旋律（意外结果，隐藏结果）：获得艺术奢侈品 15、星海货币 30（支出星海货币 12、生物质 12）；或仅获得艺术奢侈品 4（支出星海货币 14、知识 10）。

该链以知识传输协议为锚点，后续节点均带随机性，回报与风险并存。

### 4.6.4 罗莎·花冠（rosa-luxury）

1. 玫瑰星球账册（星港贸易授权）：支付生物质 30、知识 30、星海货币 20，获得星海货币 20，并授予 `TS-3 玫瑰星球`；固定在星海交易港添加艺术奢侈品双向贸易权限。
2. 竞争者尾随（意外结果，隐藏结果）：获得星海货币 40、艺术奢侈品 10（支出星海货币 20、生物质 15）；或仅获得星海货币 10（支出星海货币 25、合金 10）。
3. 独家代理合同（稀有资源交易）：支付生物质 25、合金 15、知识 15，获得星海货币 50、艺术奢侈品 18。签署后月面成为玫瑰星球在太渊星域的唯一供应商。

该链是奢侈品经济的核心来源，星港授权后持续产出艺术奢侈品。

### 4.6.5 阿缇娅·灰舟（atya-refuge）

1. 家园落难的幸存者（索取资源）：支付氧气 8、生物质 6，获得人口 1。阿缇娅和族人请求留在月面，怀中坐标核仍在发热。
2. 追兵抵达（长链抉择）：支付星海货币 40、合金 40、量子计算核心 1 赎回幸存者，避免她们被交回黑夜。
3. 伊甸园坐标（物资换科技）：支付知识 25，获得水 15、生物质 15，并授予 `TC2-2 发现伊甸园`。

该链刻画前期投入与后期回报。`TC2-2` 是中期外星科技，后续外星人设计必须保留“生态行星坐标”这一来源。

## 4.7 长事件链（晚期）

### 4.7.1 欧里·无重力（orri-leviathan）

1. 无重力的骨骼（稀有资源交易）：支付月壤 60、星海货币 16、氧气 30，获得合金 80、量子计算核心 2。某些骨骼必须先学会遗忘月球，否则飞不远。
2. 潮汐校准（意外结果，隐藏结果，默认礼送跳过）：获得量子计算核心 2（支出星海货币 8、合金 15）；或损失合金 60、星海货币 12、量子计算核心 1。高能潮汐试验没有明确保证。
3. 黑洞约束箴言（物资换科技）：支付合金 150、星海货币 32、量子计算核心 5，获得量子计算核心 2，并授予 `TE3-0 外星科技：微型黑洞约束`。

该链刻画星舰工程与高阶能源之间的联系。玩家前期接受其试验风险，后期可能得到归元装置所需的关键外星科技。

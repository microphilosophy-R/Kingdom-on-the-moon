# 4. 角色与事件链

> 本文档说明 `src/data/characterRegistry.ts`、`src/data/eventRegistry.ts` 与 `src/events/` 中的角色 / 事件实现。文档可能滞后，若与代码不一致，以代码为准。

## 4.1 总则

- 角色与事件是两个独立数据容器：角色保存身份、物种、专长、雇佣加成与肖像；事件链保存相遇文本、阶段、互动类型、资源变化与科技奖励。
- 事件链按时期分级（early / mid / late），与设施建设进度联动解锁（`getAvailableEventChains`）。
- 外星科技只能引用 [科技与政策](technology-policy.md) 的外星科技索引。

## 4.2 数据结构

角色（`Role` / `CharacterRecord`）字段：`charId`、`id`、`name`、`species`、`glyph`、`portrait`、`specialty`、`boost`、`retainerCost`、`quote`。

事件链（`EventChain`）字段：`id`、`roleId`、`arc`（simple / long）、`stage`、`events[]`。

事件节点（`EventStep`）字段：`id`、`eventCode`、`title`、`body`、`interaction`、`offer`（give / take / tech）、`rolls`（随机结果）、`hireCost`、`concealed`、`note`、`defaultAction`。

## 4.3 互动类型

`EventInteraction`（`src/events/types.ts`）：`techTrade`（物资换科技）、`starportTrade`（星港贸易授权）、`hire`（雇佣角色）、`gift`（收下礼物）、`request`（索取资源）、`accident`（意外结果）、`rareTrade`（稀有资源交易）、`chainChoice`（长链抉择）。

注：`hire` 已定义但当前事件链未使用；「留任」为独立操作，不占用该互动类型。

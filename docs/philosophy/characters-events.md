# 4. 角色与事件链

## 4.1 总则

本章是外星角色与事件链的规则来源。角色与事件是两个独立数据容器：角色保存身份、专长、雇佣加成与美术占位字段；事件链保存相遇文本、阶段、交互类型、资源变化与科技奖励。

设计原则：

- 不做简单随机重复事件，避免玩家被同质事件打断。
- 大量使用只包含一个事件的简单事件链，用于刻画星海相遇的偶然性。
- 少量人物拥有完整长事件链，需要玩家在前期或中期投入，以期在后期获得回报。
- 外星科技必须引用 [科技与政策](technology-policy.md) 的外星科技索引，不得临时发明科技。
- 本阶段不生成美术资源；角色数据只保留 `glyph`、物种、肖像文本等可替换占位字段。

## 4.2 数据容器

角色容器字段：

```text
角色代号
角色名称
物种 / 来源
视觉占位 glyph
肖像文本
专长设施
雇佣加成
留任成本
代表台词
```

事件链容器字段：

```text
事件链代号
关联角色代号
链类型：simple / long
时期：early / mid / late
事件节点列表
```

事件节点字段：

```text
事件代号
事件标题
事件正文
互动类型
资源收入
资源支出
科技奖励
是否隐藏结果
是否推进下一节点
```

## 4.3 互动类型

| 类型 | 用途 |
| --- | --- |
| 物资换科技 | 以存储物资获取特定科技。 |
| 星港贸易授权 | 固定在 S 星海交易港添加贸易方式后获得科技，尤其用于贸易类科技。 |
| 雇佣角色 | 花费资源或直接留任，为特定区域或全局带来加成。 |
| 收下礼物 | 无资源支出，获得物资或科技。 |
| 索取资源 | 对方请求资源，可能推进后续事件链。 |
| 意外结果 | 无明确数值提示，需要玩家从文字推断，可能损失或获得资源。 |
| 稀有资源交易 | 交易获得量子计算核心、艺术奢侈品等稀有资源。 |
| 长链抉择 | 多节点人物事件中的阶段性选择。 |

## 4.6 长事件链

### 4.6.1 欧里·无重力

1. 无重力的骨骼：交易获得合金和量子计算核心。
2. 潮汐校准：隐藏结果，可能损失合金或获得量子计算核心。
3. 黑洞约束箴言：支付合金和电力，获得 `TE3-0 外星科技：微型黑洞约束`。

该链刻画星舰工程与高阶能源之间的联系。玩家前期接受其试验风险，后期可能得到归元装置所需的关键外星科技。

### 4.6.2 阿缇娅·灰舟

1. 家园落难的幸存者：幸存者乞求留在星球，玩家支付氧气和生物质，获得人口。
2. 追兵抵达：玩家需要交出人质或支付赎金；当前实现为支付星海货币与合金推进事件。
3. 伊甸园坐标：赎金换来时间，数年后获得水、生物质与 `TC2-2 发现伊甸园`。

该链刻画前期投入与后期回报。`TC2-2` 是中期外星科技，后续外星人设计必须保留“生态行星坐标”这一来源。

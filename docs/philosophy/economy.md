# 1. 经济系统

## 1.1 总则

本章是经济系统的唯一规则来源。后续实现、UI、数值平衡与文案，均以本章为准。

- 代号仅用于索引，不改变建筑名称本身。

  - E1：日冕能源署
  - E2：月冕能源署
  - E3：归元装置
  - C1：静海采掘署
  - C2：西海采掘署
  - B：水培生态球
  - F：天工精炼署
  - P：伊犁河谷
  - R：月穹生态环
  - S：星海交易港
  - K：月面王城
  - L：问天研究实验室
  - H：翡翠宫
  - M：新月府
  - D：冠冕星舰坞
- 电力是经济系统的基石，只能由基地生产，不能交易，也不模拟储量。
- 除电力外，其余资源都以库存形式管理，可出现赤字；资源为负时以红字提示。
- 当某资源的赤字绝对值超过其最大储量时，依赖该资源的相关生产建筑会停止运行，直到恢复为盈余。
- 电力不足时，设施按优先级降吞吐率，同时削减投入与产出，直到恢复平衡。
- 维持生命系统产出的建筑优先级最高，其次是生产建筑，再次是科研建筑，最后是星舰建筑。
- 人口由系统自动分配到当前所有建筑；人口不足时，建筑吞吐率按比例收缩。
- 一般建筑始终处于“扩大 / 保持 / 缩小”三态之一，扩产与减产都由算法决定，玩家只设置权重。
- 建筑单位规模每次以 1 个人口单位为基本增减量，调整需要固定时间。
- 所有设施都在初始地图上，点击后进入详情页；一般设施页只展示配方与产量，特殊设施有专属界面。

## 1.2 电力

获取方式：E1 日冕能源署，E2 月冕能源署，E3 归元装置。

规则：

- 电力是经济系统的基础资源，不能交易，也不进入库存模拟。
- 大部分设施都依赖电力输入；缺电时，系统按优先级自动降载。
- 储能装置与电网科技只作为效率科技存在，不引入电力库存。

## 1.3 水

获取方式：C1 静海采掘署，C2 西海采掘署，R 月穹生态环，S 星海交易港。

规则：

- 水在开局具有较高储量，但本质上仍是不可再生资源。
- 水资源不足时产生赤字，相关生产建筑会尝试重新调整，直到恢复为盈余。
- 水资源赤字会导致人口下降，下降速率随赤字增长而提高，并存在上限。
- 水的产出必须谨慎控制，不应长期维持大量盈余，以保持其在太空环境中的珍贵感。

## 1.4 氧气

获取方式：B 水培生态球，F 天工精炼署，E1 日冕能源署，P 伊犁河谷，R 月穹生态环，S 星海交易港。

规则：

- 氧气在开局具有较低储量，是维系生命与生产的必须资源。
- 氧气不足时产生赤字；相关生产建筑会尝试重新调整，直到恢复为盈余。
- 氧气赤字会导致人口下降，下降速率随赤字增长而提高，并存在上限。
- 氧气的供需平衡应始终保持紧张感，但不得让系统频繁崩盘。

## 1.5 生物质

获取方式：B 水培生态球，P 伊犁河谷，R 月穹生态环，S 星海交易港。

规则：

- 生物质在开局具有较低储量，是维系生命和生产的必须资源。
- 生物质不足时产生赤字，相关生产建筑会尝试重新调整，直到恢复为盈余。
- 生物质赤字会导致人口下降，下降速率随赤字增长而提高，并存在上限。
- 生物质是控制人口的关键资源，前期产量增长应刻意缓慢，以模拟殖民初期的脆弱性。

## 1.6 月壤

获取方式：C1 静海采掘署，C2 西海采掘署，S 星海交易港。

规则：

- 月壤代表初级工业品，是前期重要的贸易出口资源。
- 后期由于单位产值较低，月壤会逐渐成为进口资源。
- 月壤出现赤字时，相关生产建筑停止运行，直到恢复为盈余。

## 1.7 合金

获取方式：F 天工精炼署，C2 西海采掘署，P 伊犁河谷，S 星海交易港。

规则：

- 合金代表中级工业品，是中期重要的贸易出口资源。
- 合金是建造星舰与后期高级设施的重要材料。
- 合金赤字时，相关生产建筑停止运行，直到恢复为盈余。

## 1.8 量子计算核心

获取方式：L 问天研究实验室，S 星海交易港。

规则：

- 量子计算核心代表高级工业品，是后期重要的贸易出口资源，也是后期高级建筑的材料。
- 问天研究实验室在后期通过消耗电力、水、氧气和合金生产该资源，前置条件是原子阵列光刻机研究。
- 游戏初期默认拥有一定数量，用于让玩家至少能解锁一座高级建筑。

## 1.9 星海货币

获取方式：K 月面王城，F 天工精炼署。

规则：

- 星海货币是星海交易港的结算货币。
- 月面王城通过征税获得铸币权，星海货币与人口成正比。
- 天工精炼署在后期可通过重原子炼金术相关科技获得星海货币。
- 当星海货币出现赤字时，自动购买暂停；恢复为盈余后继续交易。

## 1.10 人口

获取方式：K 月面王城，H 翡翠宫，M 新月府，S 星海交易港。

规则：

- 人口不是普通库存品，而是可用居民总数与劳动力总量。
- 月面王城是前期人口建筑；翡翠宫是中期人口建筑，单位人口资源消耗更高，但会产出艺术奢侈品；新月府是后期人口建筑，单位人口资源消耗更低，但需要完成月穹生态环。
- 解锁 `TS-1 星际劳工` 后，星海交易港可进行其它星域人力资源的双向贸易。
- 生产建筑都需要占用人口；人口不足时，建筑吞吐率按比例收缩。
- 人口优先进入更高级的人口建筑，默认顺序为翡翠宫 > 月面王城 > 新月府，政策可以改变该优先级。
- 人口供给会按当前建筑配方和当前建筑规模等比例消耗资源。

## 1.11 知识

获取方式：L 问天研究实验室，S 星海交易港。

规则：

- 知识用于解锁更先进的科技。
- 问天研究实验室是前期知识来源。
- 解锁 `TS-2 知识传输协议` 后，星海交易港可进行知识的双向贸易。

## 1.12 艺术奢侈品

获取方式：H 翡翠宫，S 星海交易港。

规则：

- 艺术奢侈品是部分外星人必需的物资，也可用于贸易。
- 翡翠宫是其主要来源。
- 解锁 `TS-3 玫瑰星球` 后，星海交易港可进行艺术奢侈品的双向贸易。

## 1.13 经济运行与优化策略逻辑

- 玩家扮演国王，决定经济发展的方向与目标权重；通常不需要手动干预，细节由算法完成。
- 游戏最小时间单位为天，称为“御日”。
- 正常速度为现实时间每 1.6 秒推进 1 御日；加速为现实时间每 1 秒推进 1 御日。
- 所有资源按天结算，UI 显示库存与每日净变化。
- 游戏在第 1000 御日结束，预期单局现实时长约 1 小时。
- 内置优化策略每 20 御日执行一次，并在次日通过简要“月度报告”告知玩家优化结果。
- 人口规模应控制在较小范围开局，例如 10；后期可增长到约 500。
- 前期本地人口增长主要依靠外星人事件，每次成功留任都会增加 1 人口。
- 所有数值先以“单位人口”和“资源价值”为基准重算，再填入建筑生产方式表。
- 科技只改变可用选项、效率或市场权限；科技本身不得隐式增加资源，除非科技表明确写出增益方式。

## 1.14 单位人口消耗基准

本节定义人口建筑与生产建筑的共同计量口径。后续所有建筑配方、自动化算法和 UI 说明，均以本节为数值基准。

- 1 单位人口表示 1 个可被住房、生产建筑或项目占用的居民 / 劳动力单位。
- 1 单位建筑规模默认占用 1 单位人口；若某生产方式不需要人口，必须在该建筑说明中明确写出。
- 人口建筑的输入代表维持、居住与社会组织成本；人口建筑的输出代表人口容量、人口增长或可用劳动力供给。
- 普通生产建筑不在配方中重复写基础居民生活成本；其人口占用由全局人口分配系统处理。
- 若生产方式直接消耗“人口”，表示长期项目或事件占用额外人力，不等同于普通岗位编制。

基础生命维持包：

| 层级 | 适用建筑 | 单位人口输入 | 总价值 | 说明 |
| --- | --- | --- | --- | --- |
| 基础居民 | K 月面王城 | 水 0.4、氧气 0.3、生物质 0.3 | 1.0 | 前期标准人口成本，作为所有人口数值的基准。 |
| 宫廷居民 | H 翡翠宫 | 水 0.5、氧气 0.4、生物质 0.5 | 1.4 | 中期高消耗人口，换取艺术奢侈品和外交价值。 |
| 生态居民 | M 新月府 | 水 0.2、氧气 0.2、生物质 0.3 | 0.7 | 后期低消耗人口，需要月穹生态环完成后解锁。 |

| 产出类型 | 基准值 | 说明 |
| --- | --- | --- |
| 普通人口供给 | 1.0 人口 | 每 1 单位住房规模提供 1 单位稳定人口。 |
| 高组织度人口供给 | 1.2 人口 | 用于 K 月面王城或 M 新月府等治理 / 生态效率较高的住房。 |
| 人口建筑附带货币 | 0.5-1.0 星海货币 | 只用于政府税收、宫廷消费或特殊政策，不作为所有人口建筑的默认产出。 |
| 人口建筑附带奢侈品 | 0.5-1.0 艺术奢侈品 | 只用于 H 翡翠宫等文化人口建筑。 |

## 1.15 资源价值与星海货币

星海货币是唯一通用货币。本表定义每 1 单位资源折算为多少星海货币价值；它既是贸易价格的基准，也是生产方式重算时的价值权重。实际市场买卖可以在此基础上按供需、事件与自动购买惩罚浮动。

| 资源 | 基准价值 | 交易规则 |
| --- | ---: | --- |
| 电力 | 0.5 | 不可交易，不进入库存；仅用于配方价值与自动化权重计算。 |
| 水 | 1.0 | 可交易；生命维持核心资源，价格不得长期低于 1.0。 |
| 氧气 | 1.0 | 可交易；生命维持核心资源，价格不得长期低于 1.0。 |
| 生物质 | 1.0 | 可交易；人口控制核心资源，前期供应应刻意紧张。 |
| 月壤 | 1.0 | 可交易；初级工业品，是前期工业链和中期能源链的基础。 |
| 合金 | 8.0 | 可交易；中级工业品，星舰与中后期建筑主要材料。 |
| 量子计算核心 | 128.0 | 可交易；高级工业品，数量极少但单价极高。 |
| 星海货币 | 1.0 | 记账单位；自动购买、贸易结算和税收均以此为基准。 |
| 人口 | 5.0 | 不是普通库存品；仅在 TS-1 解锁后进入双向劳工贸易。 |
| 知识 | 2.0 | 科技解锁资源；仅在 TS-2 解锁后进入双向贸易。 |
| 艺术奢侈品 | 3.0 | 外交与高级贸易资源；仅在 TS-3 解锁后进入双向贸易。 |

价值计算规则：

- 生产方式价值 = 输出资源价值总和 - 输入资源价值总和。
- 电力虽然不可交易，仍按 0.5 计入配方价值，用于比较不同生产方式的经济效率。
- 人口建筑重算时，先比较其生命维持输入是否符合 1.14，再单独评估人口、税收与奢侈品输出；不得把人口建筑当作普通贸易套利建筑。
- D 冠冕星舰坞和 R 月穹生态环的建设阶段不追求正净值，它们消耗资源换取项目进度或世界状态。
- S 星海交易港不产生固定净值；其价值来自交易权限、自动购买和事件市场。

初步结论：

- 所有建筑已经能归入明确时期；只有 L 与 R 是跨时期建筑，需要在界面中按生产方式或阶段显示时期。
- 早期水恰好持平，说明开局不能随意扩张 B/K；这符合月面殖民的紧张感。
- 中期合金来源有 4 个入口，其中 P 需要外星科技后才提供合金；默认中期链的水与月壤会轻微短缺，后续调配方时应先检查水、月壤和氧气的利润率。
- 晚期资源不缺基础生命维持，缺的是合金，以及第三阶段集中需要的量子计算核心、水和生物质；D 的胜利推进应围绕“按日合金消耗 + 阶段材料储备”形成压力。

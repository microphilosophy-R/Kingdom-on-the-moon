# 美术风格总纲

本文件是《月面王国》所有美术资产的统一风格基准。角色、场景、建筑、UI 与提示词模板均须遵循本总纲，不得与之冲突。若与 [DESIGN.md](../../DESIGN.md) 的视觉系统描述出现冲突，以 DESIGN.md 的色值与字体规格为准；叙事与氛围以 [PRODUCT.md](../../PRODUCT.md) 与 [docs/philosophy/story.md](../philosophy/story.md) 为准。

## 1. 世界观与氛围基调

- 故事舞台：气态巨行星太渊的第七卫星"月面"，一颗无大气、灰色尘壤、被太渊潮汐锁定的苦寒殖民地。详见 [docs/philosophy/story.md](../philosophy/story.md)。
- 主角身份：陈林，被做局称王的基层公务员，真实目标是密造御座号归乡，而非追求繁荣。
- 品牌气质：冷峻、仪式化、有一点荒诞。科技系统要精确，王权语言要克制而郑重。
- 情感曲线：月壤的脆弱感始终可见，繁荣不是理所当然；荒诞来自官僚做局与外星封君律，不来自滑稽夸张。

## 2. 视觉主题

月面政务舱内的暖灰仪表台。界面与美术不是深色宇宙舱，而是被月尘、羊皮纸、陶瓷面板与低亮度黄铜控件共同照亮的殖民地执政桌面。冷色只作为舷窗阴影、科技状态、星海信号和少量风险提示出现，不能承载大面积工作区。

关键词：月壤暖灰、羊皮纸、陶瓷面板、低亮度黄铜、淡金色太渊目光、舷窗冷阴影、克制仪式感。

## 3. 色彩规范

所有颜色使用 OKLCH，不使用纯黑或纯白。色值直接引用 [DESIGN.md](../../DESIGN.md#L8-L22)，美术资产须与之匹配。

| 令牌 | OKLCH | 用途 |
| --- | --- | --- |
| shell | `oklch(92% 0.018 86)` | 页面底色与大面积背景 |
| surface | `oklch(97% 0.010 86)` | 普通面板、列表、卡片 |
| surface-raised | `oklch(94% 0.014 84)` | 工具栏、资源条、选中前弱层级 |
| parchment | `oklch(90% 0.022 82)` | 报告、政策、事件正文等叙事区域 |
| ink | `oklch(24% 0.024 250)` | 主文本 |
| muted | `oklch(47% 0.018 250)` | 说明文字和次级数字 |
| line | `oklch(73% 0.018 84)` | 1px 分隔线 |
| brass | `oklch(55% 0.105 76)` | 主操作、当前选择、可执行状态 |
| brass-soft | `oklch(94% 0.040 78)` | 选中背景和 hover |
| signal | `oklch(52% 0.075 205)` | 科技、信息、星海信号，不作大面积背景 |
| success | `oklch(55% 0.090 145)` | 吞吐正常、正收益 |
| danger | `oklch(56% 0.120 28)` | 赤字、失败、缩减 |

辅助叙事色（仅用于插画与场景，不进入 UI 工作区）：

- 太渊金：`oklch(70% 0.110 75)`，气态巨行星悬于天顶的淡金目光，是月面寒冷中唯一的暖源。
- 月壤灰：`oklch(58% 0.012 85)`，地表尘壤的基准灰，略带暖调，区别于纯中性灰。
- 舷窗冷影：`oklch(38% 0.025 240)`，阴影与舷窗外的深空冷调，只用于暗部与远景。

## 4. 字体

UI 主字体：`Noto Sans SC`, `Microsoft YaHei UI`, `Segoe UI`, `system-ui`, `sans-serif`。标题可使用 `Noto Serif SC`, `Source Han Serif SC`, `Songti SC`, `serif` 保留王权气质。按钮、标签、数据、表格全部使用 UI 字体或等宽数字字体。

插画与概念图中的文字应尽量少；必要文字使用衬线体，呼应王权仪式感，不使用赛博霓虹字形。

## 5. 构图与笔触

- 构图偏好：留白建立秩序，而非用重复卡片堆砌。主体居中或偏左，右侧留出信息区，呼应 [docs/philosophy/ui.md](../philosophy/ui.md#L11-L13) 的星球停靠规则。
- 笔触：偏向克制的厚涂与平涂结合，边缘清晰但不锋利；避免水彩晕染、油画厚堆与动漫赛博高光。
- 材质表达：羊皮纸纤维、陶瓷釉面、黄铜氧化层、月壤颗粒感是核心材质语言。
- 光照：单一暖源（太渊金光或黄铜仪表灯）为主，冷光为辅；阴影柔和，不使用硬切黑白对比。

## 6. 反向参考（必须避免）

直接引用 [PRODUCT.md](../../PRODUCT.md#L19-L22) 的反参考清单：

- 避免泛紫色科幻。
- 避免空洞的赛博霓虹。
- 避免手游式红点堆叠。
- 避免难读的微小数据表。

补充美术禁项：

- 不使用纯黑纯白、不使用高饱和荧光色。
- 不使用机甲流线高光、不使用日漫大眼比例。
- 不使用哥特尖拱与过度繁复的纹饰；王权符号保持几何克制。
- 不使用与月面苦寒氛围冲突的鲜艳花草与蓝天。

## 7. 资源命名规范

所有美术资源使用小写英文 + 连字符，前缀分类，置于 `src/assets/` 或 `public/textures/` 下。

| 分类 | 前缀 | 示例 |
| --- | --- | --- |
| 角色肖像 | `char-` | `char-chenlin.jpg`、`char-sava.jpg` |
| 建筑图标 | `bldg-` | `bldg-e1-icon.png`、`bldg-d-yard.jpg` |
| 场景背景 | `scene-` | `scene-moon-surface.jpg`、`scene-taiyuan-sky.jpg` |
| UI 元素 | `ui-` | `ui-btn-brass.svg`、`ui-frame-parchment.svg` |
| 资源图标 | `res-` | `res-water.svg`、`res-alloy.svg` |
| 科技图标 | `tech-` | `tech-te1-1.svg` |
| 星球纹理 | `planet-` | `planet-moon.jpg`（置于 `public/textures/planets/`） |

命名要求：使用建筑代号或角色 id，不使用中文；同一资源的多分辨率版本以 `@2x`、`@3x` 后缀区分。

## 8. 一致性检查清单

产出任何美术资产前，逐条确认：

- 色彩是否取自第 3 节令牌，无纯黑纯白与高饱和荧光。
- 暖灰为主、冷色仅作信号或阴影，工作区不出现大面积冷色。
- 王权符号是否克制几何，未滑向哥特繁复或赛博霓虹。
- 是否保留了月壤脆弱感与荒诞官僚底色，未变成英雄史诗。
- 命名是否符合第 7 节规范。

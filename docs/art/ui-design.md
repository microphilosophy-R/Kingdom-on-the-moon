# UI 视觉设计规范

本文件定义《月面王国》界面的视觉细节。信息架构与功能入口以 [docs/philosophy/ui.md](../philosophy/ui.md) 为准，色值、字体、组件样式以 [DESIGN.md](../../DESIGN.md) 为准；本文件补充图标、插画、边框、按钮与背景的美术细则，不修改任何功能逻辑。

## 1. UI 美术总则

- 界面是"月面政务舱内的暖灰仪表台"，不是深色宇宙舱。工作区以暖灰、羊皮纸、陶瓷面板为主。
- 秩序来自分区、符号、星球视角与留白，而非重复卡片堆砌。
- 王权语言克制而郑重：黄铜是唯一的"权力色"，冷蓝只作信号与科技状态。
- 所有视觉元素必须服务于"可解释的取舍"——先说明代价，再要求选择。

## 2. 色彩与字体

直接引用 [style-guide.md](style-guide.md#3-色彩规范) 与 [DESIGN.md](../../DESIGN.md#L8-L28)。UI 资产不得引入令牌外色值。

- 工作区底色：shell；面板：surface / surface-raised；叙事区：parchment。
- 主操作：brass；选中背景：brass-soft；分隔线：line。
- 信号/科技：signal（小面积）；正收益：success；赤字/失败：danger。
- 字体：UI 用 Noto Sans SC 系；标题用 Noto Serif SC 系保留王权气质。

## 3. 组件样式

### 3.1 按钮与选中态

- 主按钮：黄铜实底 brass，文字 ink 或 shell，圆角 4–8px。
- 次按钮：浅面板 surface + 暖灰边框 line，文字 ink。
- 选中态：完整 brass-soft 背景 + 完整边框，不使用侧边色条。
- 禁用态：降低对比但保持可读，不使用纯灰填充。

### 3.2 面板与边框

- 普通面板：surface 或 parchment 底，1px line 边框，圆角 4–8px。
- 叙事面板（事件正文、政策、报告）：parchment 底，衬线标题，保留羊皮纸纤维质感。
- 不使用阴影漂浮、不使用毛玻璃高斯模糊；层级靠色差与 1px 边框区分。

### 3.3 图标风格

- 风格：线性 + 微面，统一描边粗细（2px 等效），端点圆角。
- 配色：单色 brass 为主，状态色仅用于状态指示（success / danger / signal）。
- 资源图标 `res-`：抽象符号化，不写实；例如水用一滴几何水珠，合金用叠层方片。
- 科技图标 `tech-`：几何仪式感，呼应建筑代号；不使用机甲高光。
- 建筑图标 `bldg-`：剪影化外观，对齐 [environment-design.md](environment-design.md#4-建筑外观索引)。

## 4. 关键界面视觉

### 4.1 首页与星球

- Three.js 星球是第一视觉对象，居中可拖拽；点击后缩小停靠左侧，右侧出建筑列表。
- 星球周围不使用边框卡片包裹，避免和球体割裂；贴图来自 `public/textures/planets/`，随机选择。
- 顶部固定资源视图，底部固定 tab 工具条。规则见 [ui.md §5.1](../philosophy/ui.md#L7-L13)。

### 4.2 政策页（K 月面王城）

- 展示王城等级、岗位容量、已分配人口、每日结算、吞吐率、政策签发台、上一轮 20 御日执行报告。
- 视觉：parchment 报告区 + 黄铜签发台；当前政策用 brass-soft 高亮，冷却用 line 弱化。
- 政策卡片须先显示"代价"再显示"效果"，呼应设计原则。

### 4.3 科技树（L 问天研究实验室）

- 按前期/中期/晚期从左到右排布，可横向滚动；阶段间线性链接。
- 卡片显示科技名称、图像位、前置、所需知识、描述、涉及图标、研究进度。
- 当前研究卡片放大；已完成实线边框，未研究虚线边框，锁定弱化样式。卡片不显示内部代号。

### 4.4 星舰页（D 冠冕星舰坞）

- 展示御座号项目进度、三阶段物资供应、人力供应、胜利条件。
- 视觉：星舰龙骨剪影对准太渊方向；阶段进度用 brass 填充，缺口用 danger 提示。
- 氛围应暗示"逃生"而非"征服"——低调的焊接火花微光，不使用英雄式发射特效。

### 4.5 异客事件弹窗

- 弹窗承载事件链正文、资源变化、留任成本、事件操作。
- 正文区用 parchment 暖灰叙事面板，不使用整块深冷色。
- 角色肖像置于正文旁，对齐 [character-design.md](character-design.md#4-外星访客视觉档案)。
- 资源变化用 `res-` 图标 + 等宽数字，赤字 danger、盈余 success。

## 5. 背景与纹理

- 页面底纹：shell 暖灰，可叠加极低透明度的月壤颗粒噪点，不抢内容。
- 叙事区纹理：parchment 羊皮纸纤维，边缘略磨损。
- 仪表台纹理：陶瓷釉面微反光，黄铜件氧化层，不使用金属高光。
- 不使用赛博网格、不使用星空铺底、不使用紫色辉光。

## 6. 动效

- 满足"支持减少动态效果"的无障碍要求；所有操作可由键盘触发。
- 动效克制：状态切换用淡入淡出与短位移，不使用弹性回弹与粒子飞溅。
- 星舰进度推进可有缓慢的光带流动，但不得闪烁刺眼。

## 7. 无障碍

遵循 [PRODUCT.md](../../PRODUCT.md#L32) 与 [DESIGN.md](../../DESIGN.md#L32)：

- 满足 WCAG AA 文本对比度。
- 颜色不作为唯一状态标识；赤字与盈余须同时用图标/文字区分。
- 支持减少动态效果；所有操作可由键盘触发。

## 8. 禁忌

- 不使用手游式红点堆叠；状态用色块、边框与文字说明，不用闪烁红点轰炸。
- 不使用深色宇宙舱作为工作区底色；冷色仅作舷窗、信号与阴影。
- 不使用难读的微小数据表；数字用等宽字体并保留足够行高。
- 不使用与 [DESIGN.md](../../DESIGN.md) 冲突的色值、圆角与字体。

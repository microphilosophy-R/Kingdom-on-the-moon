# 角色设计规范

本文件定义《月面王国》所有角色的视觉设计语言。角色数据字段与事件链规则以 [docs/philosophy/characters-events.md](../philosophy/characters-events.md) 为准，本文件只负责外观、材质、姿态与肖像提示词，不修改任何 id、数值或互动类型。

## 1. 设计原则

- 角色是经济变量，也是可记住的人。视觉要让人一眼记住物种特征，而非堆砌细节。
- 外星访客保留"他者感"：不套用地球生物的五官比例，避免拟人化萌化。
- 王权克制：陈林与外星角色都不过度华丽；仪式感来自材质与姿态，不来自装饰堆叠。
- 色彩遵循 [style-guide.md](style-guide.md#3-色彩规范)，以暖灰、羊皮纸、黄铜为主，冷色仅用于个别物种的生理特征。

## 2. 主角：陈林（月面王）

身份与叙事见 [docs/philosophy/story.md](../philosophy/story.md)。视觉要点：

- 体态：中等身形，肩背因长期案牍略前倾；坐姿被龙椅束缚，双足不离开地面，强调"困守"。
- 面容：普通东亚中年面孔，不英俊也不丑陋；眉头微蹙，眼神清醒而无奈，非英雄锐光。
- 服饰：拓殖署基层公务员制服，灰蓝偏暖（shell 色），胸前别一枚被强行加挂的黄铜王徽；肩线有褶皱，显示衣服是临时套上的。
- 龙椅：仿古黄铜与月壤陶土拼接，扶手压着那份他没签名的封君诏书。
- 配色：制服 shell 暖灰、王徽 brass、诏书 parchment、背景舷窗透入太渊金光与冷阴影。
- 关键意象：双足被一条由月壤微粒构成的细弱光带锁在地砖上——封君律的可视化，纤细但不可断。

肖像提示词草案见 [prompt-templates.md](prompt-templates.md)。

## 3. 外星访客设计总则

外星访客数据见 [docs/philosophy/characters-events.md](../philosophy/characters-events.md#4.4-已设计角色)。视觉需对齐 `portrait` 字段与 `glyph` 占位符。

- 形体：以抽象几何或自然现象为骨架（甲壳、孢囊、潮汐、石英、声波、账册、烧焦聚合毯），不强制双足人形。
- 材质：呼应月面美术语言——陶瓷釉、氧化黄铜、琥珀、石英、银灰潮汐、薄雾织物。
- 姿态：使节式克制，不张扬；手中常持其专长设施的代表物（晶体、孢囊、坐标核等）。
- 配色：以暖灰为底，每角色一个辨识主色，取自 style-guide 令牌或其邻近色，避免高饱和。

## 5. 周衍（帝王 / 上级）

授封仪式的"上位者"，现已回母星。视觉要点：

- 服饰：拓殖署署长代表制服，比陈林更合身更挺括，深暖灰（surface-raised），袖口有黄铜署徽。
- 面容：中年上位者，表情得体而疏离，念戏仿诏书时带着公事公办的微笑。
- 姿态：登船回母星，背对月面；只留下一个剪影式背影，象征"他走了，陈林没走"。
- 配色：制服深暖灰、署徽 brass、背景轮换船舷梯的冷阴影。

## 6. 表情与姿态准则

- 陈林：无奈 > 愤怒；清醒 > 雄心。眉头微蹙、嘴角平直，不出现狞笑或痛哭。
- 外星访客：以材质与形体变化替代表情；如 nix 用王徽明灭表达情绪，orri 用潮汐涨落表达语调。
- 群像：陈林坐于龙椅，外星访客立于或悬浮于前方，形成"被困之王接见来客"的构图母题。

## 7. 禁忌

- 不把外星访客画成地球萌兽或日漫拟人。
- 不给陈林加王冠、披风、权杖等华丽王权符号；他的王权只有那枚被强挂的黄铜徽。
- 不使用高饱和荧光色与赛博霓虹高光。
- 不改变角色 id、物种、专长设施、加成数值；这些以 characters-events.md 为准。

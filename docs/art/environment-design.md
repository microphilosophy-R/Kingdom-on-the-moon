# 场景与建筑设计规范

本文件定义《月面王国》的环境、建筑外观与材质语言。建筑功能、代号、配方与数值以 [docs/philosophy/buildings.md](../philosophy/buildings.md) 为准，本文件只描述外观、材质、配色与氛围，不修改任何 id 或规则。

## 1. 环境总则

- 主舞台：气态巨行星太渊的第七卫星"月面"。无大气、灰色尘壤、被太渊潮汐锁定。详见 [docs/philosophy/story.md](../philosophy/story.md)。
- 天空：没有蓝天。天顶永远悬着太渊——一只淡金色的巨眼，占据大半个天穹。
- 地表：起伏平缓的灰色尘壤丘陵，散落原住民留下的封君台遗迹与陨击坑。
- 光照：太渊金光为唯一暖源，低角度斜射，拉出长影；背阳面是舷窗冷阴影。不出现地球式日照。
- 氛围：寂静、干燥、略带荒诞的仪式感；风是稀薄的，听不见，只看见尘壤缓慢迁移。

## 2. 地标场景

### 2.1 封君台遗迹

授封仪式发生地，太渊星域原住民留下的古老构筑物。

- 形态：低矮的环形石台，由月壤陶土与未知合金拼接，台中央置龙椅。
- 材质：陶土表面风化出细密裂纹，合金件氧化成 brass 暖色，刻有封君律的几何纹。
- 氛围：金光斜照台面，龙椅投下长影；仪式后只剩陈林一人独坐，遗迹显得空旷而冷峻。

### 2.2 月面王城（K）

前期人口与政府建筑，外观见 [buildings.md §2.18](../philosophy/buildings.md)。视觉要点：

- 形态：低矮的穹顶政务厅，陶瓷面板外墙，黄铜门楣，挂月面王徽。
- 材质：陶瓷釉面 shell、门楣 brass、内墙 parchment 用于政策与诏书张贴。
- 内景：龙椅置于厅中央，扶手压着封君诏书；两侧是暖灰仪表台与轮换同事的空座。

### 2.3 冠冕星舰坞（D）

胜利目标建筑，御座号秘密建造地。见 [buildings.md §2.20](../philosophy/buildings.md#L351-L376)。

- 形态：半嵌入式开放式船坞，龙骨斜指向太渊方向，仿佛要刺穿天穹。
- 材质：合金骨架 alloy、月壤混凝土基座、黄铜脚手架；龙骨内嵌御座号王座核心的微光。
- 氛围：账面上是"垦殖成果"，视觉上应流露"逃跑"的紧张感——夜间有未报备的焊接火花。

### 2.4 星海交易港（S）

见 [buildings.md §2.17](../philosophy/buildings.md#L291-L312)。

- 形态：环形对接平台，悬于月面低轨道边缘，舷窗外可见星海。
- 材质：陶瓷面板、黄铜系泊桩、薄雾状能量护盾（冷调 signal，小面积）。

## 3. 建筑外观总则

所有建筑遵循 [style-guide.md](style-guide.md) 的色彩与材质语言：

- 墙体：陶瓷面板或月壤混凝土，shell / surface 暖灰为主。
- 金属件：黄铜 brass，氧化处理，不出现高光镀铬或赛博霓虹边线。
- 玻璃与舷窗：冷调 signal 小面积使用，透出内部暖光。
- 屋顶与穹顶：低矮、平缓，呼应月面低重力与风沙环境，不使用尖塔。
- 工业管线：外露但有序，像政务档案一样排列，体现"可解释的秩序"。

## 5. 内景与细节

- 仪表台：暖灰陶瓷面板，黄铜旋钮与拨杆，1px line 分隔；显示等宽数字，不用红点堆叠。
- 羊皮纸文书：政策、诏书、月度报告使用 parchment 底色，衬线体，边缘略有月壤微粒。
- 舷窗：冷调深空背景，远处太渊金光与星海信号点；舷窗是冷暖对话的边框。
- 管线：外露但贴墙有序排列，接头处有黄铜编号牌，呼应"可解释的秩序"。

## 6. 氛围变化

随游戏推进，环境应呈现阶段变化（不改变数值，仅视觉）：

- 早期：灰冷、空旷，仅王城与少量设施亮灯，太渊金光孤悬。
- 中期：设施灯火成片，星港与翡翠宫带来暖光与薄雾，合金管线增多。
- 晚期：月穹生态环泛起微绿，星舰坞龙骨对准太渊，呈现"即将逃离"的张力。

## 7. 禁忌

- 不出现蓝天、白云、地球式植被与河流（P 伊犁河谷是室内培育，非自然地貌）。
- 不使用尖塔、哥特拱顶、赛博霓虹与高饱和荧光。
- 不把星舰坞画成英雄式发射台；它是一个公务员偷偷焊接的逃生口。
- 不改变建筑代号、名称、解锁条件与配方；这些以 buildings.md 为准。
